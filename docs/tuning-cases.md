# 调参案例

本页整理 PPO 在 LunarLander-v2 环境中的常见调参方法与案例，提供可操作的步骤与参考范围，便于教学与实战。

## 方法论
- 明确目标指标：平均奖励、成功率、价值损失稳定性、策略熵
- 单次只调整少量参数，记录变更与结果曲线
- 使用固定随机种子进行对比，避免偶然性
- 监控关键信号：ratio/clip 触发比例、KL、熵、优势分布

## 参数范围建议
- learning_rate：`1e-4 ~ 5e-4`（常用 `3e-4`）
- clip_epsilon：`0.1 ~ 0.3`（常用 `0.2`）
- entropy_coef：`0.0 ~ 0.02`（常用 `0.01`，探索不足时增大）
- value_coef：`0.3 ~ 0.7`（常用 `0.5`）
- gamma：`0.99`（可按需要微调）
- gae_lambda：`0.9 ~ 0.97`（常用 `0.95`）
- update_epochs：`5 ~ 15`（常用 `10`）
- batch_size：`32 ~ 256`（常用 `64`）
- 网络结构：`[64, 64]` 起步，训练稳定后可尝试更宽/更深

## 案例 A：探索不足导致早收敛
### 现象
- 策略熵下降过快
- 奖励曲线在中期停滞，成功率不提升
### 调整
- 增大 `entropy_coef`（如从 0.01 -> 0.02）
- 降低 `learning_rate`（如从 3e-4 -> 2e-4）避免过度更新
- 观察 `ratio` 裁剪触发比例，必要时降低 `clip_epsilon`（如 0.2 -> 0.15）
### 结果评估
- 检查 3-5 个训练窗口（每窗口若干更新）的平均奖励与熵曲线
- 成功率提升且熵在合理区间缓慢下降

## 案例 B：训练不稳定/振荡
### 现象
- 奖励曲线大幅波动
- 价值损失时大时小、优势分布不稳定
### 调整
- 降低 `learning_rate`（如 3e-4 -> 1e-4）
- 增加 `update_epochs`（如 10 -> 12）并减小 `batch_size`（如 64 -> 32）以更平滑更新
- 增大 `value_coef`（如 0.5 -> 0.6）稳定价值学习
### 结果评估
- 奖励曲线波动下降，成功率更稳定提升

## 案例 C：收敛慢/样本利用率低
### 现象
- 长时间奖励低、优势均值接近 0 且方差小
### 调整
- 增大 `update_epochs`（如 8 -> 12）
- 减小 `clip_epsilon`（如 0.2 -> 0.15）保证更保守更新但配合更多轮次
- 适度增大学习率（如 2e-4 -> 3e-4）
### 结果评估
- 奖励稳步提升，优势分布更分散，训练速度改善

## 操作流程模板
1. 固定基线配置运行若干更新，保存日志与模型
2. 选择一个问题（探索不足/不稳定/收敛慢）
3. 有针对性地调整 1-2 个参数，运行相同步数
4. 对比指标：奖励、成功率、熵、KL、价值损失、ratio 被裁剪比例
5. 记录结论与推荐配置，生成图表（保存至 `results/`）

## 常见陷阱
- 同时调整多个关键参数，导致无法定位效果来源
- 未归一化优势，带来训练不稳定
- 忽视 KL 与裁剪触发率，可能出现隐性过度更新

## 推荐可视化
- 训练奖励与成功率曲线（移动平均）
- 策略熵、KL 散度随时间变化
- ratio 分布与裁剪触发比例
- 价值损失与优势分布（均值/方差）
