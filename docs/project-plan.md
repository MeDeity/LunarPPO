# 教学计划与路线

LunarPPO 项目配套的教学路线建议为 4 周安排，可根据课程进度微调。

## 周度安排
- 第 1 周：环境搭建与基础网络
  - 安装依赖、创建虚拟环境
  - 熟悉 Gymnasium LunarLander-v2
  - 设计策略/价值网络的基础结构
- 第 2 周：PPO 核心实现
  - GAE 优势估计与回报计算
  - PPO-Clip 损失与训练循环
  - 批次采样与多轮更新
- 第 3 周：训练管道与可视化
  - 日志记录与指标监控
  - TensorBoard/曲线绘制
  - 评估与回放工具
- 第 4 周：调参与文档完善
  - 学习率/熵系数/裁剪阈值等调优
  - 结果分析与复现实验
  - 整理文档与教学材料

## 里程碑与产出
- 可稳定着陆的模型（成功率 95%+）
- 完整训练/评估脚本与可视化结果
- 系统化文档（本 /docs 目录）

## 延伸方向
- 对比不同优势估计与价值函数设计
- 加入噪声探索或自适应 KL 惩罚
- 尝试共享/分离 actor-critic 结构的影响
